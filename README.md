# Davis Trip Holidays — davistripholidays.com

Marketing site for a Himachal Pradesh travel agency: 3 verified group-tour
packages, 2 destinations, reviews, FAQs, blog, and a WhatsApp-first enquiry
flow. 100% static — free to host forever on Cloudflare Pages.

**Live:** https://davistripholidays.com · **Admin CMS:** `/admin` · **Deploy guide:** [`CLOUDFLARE-DEPLOY.md`](./CLOUDFLARE-DEPLOY.md)

---

## Highlights

- **Editorial "Field Journal" design** — full-page scroll-snap plates, sticky
  header, folio rail, Lenis smooth scrolling with a universal section-lock
  (desktop, tablet, phone) and reduced-motion fallback.
- **3 owner-verified packages** (Manali Group Escape, Himachal Group Tour,
  Full Spiti Valley Circuit) with full day-by-day itineraries, inclusions,
  exclusions — data straight from the owner's PDFs.
- **WhatsApp-first conversion** — 17 CTAs deep-link to WhatsApp with
  pre-composed messages; enquiry + customize forms compose messages
  client-side. No backend needed.
- **Git-based CMS** — edit packages, prices, reviews, FAQs, blog and site
  settings at `/admin` (Sveltia CMS). Saves commit to this repo; Cloudflare
  redeploys automatically in ~2 minutes.
- **Self-contained bundle** — all photos in `public/images`, fonts compiled
  at build time, 3D hero generated procedurally. Zero first-party server
  calls, zero external asset dependencies.
- **SEO ready** — sitemap.xml, robots.txt, JSON-LD (TravelAgency + Product),
  OG image, per-page meta, clean trailing-slash URLs.

## Tech stack

| Layer | Choice |
|---|---|
| Framework | Next.js 16 (App Router, `output: "export"` → static `out/`) |
| UI | React 19, Tailwind CSS 4, Radix UI, Framer Motion, Lenis |
| 3D | three.js / @react-three/fiber (procedural hero — no model downloads) |
| Content | Markdown + YAML frontmatter in `content/` (gray-matter, js-yaml) |
| CMS | Sveltia CMS at `public/admin/` (GitHub backend) |
| Hosting | Cloudflare Pages (free tier) — see the deploy guide |

## Quick start (local development)

Requires Node.js ≥ 20.9 (22 recommended — matches `.nvmrc` / `.node-version`).

```bash
npm install        # installs exactly what's in package-lock.json
npm run dev        # http://localhost:3000
```

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Local dev server on port 3000 |
| `npm run build` | Production static export → `out/` (what Cloudflare builds) |
| `npm run verify:export` | Audits `out/` against Cloudflare free-tier limits (files, sizes) |
| `npm run preview` | Serves `out/` on the same `wrangler pages dev` runtime Cloudflare uses |
| `npm run deploy` | Build + direct upload via Wrangler (alternative to Git deploys) |
| `npm run lint` | ESLint |

## Project structure

```
app code            src/app/            routes (home, packages, destinations, blog, …)
                    src/components/     section components (hero, packages, footer, …)
                    src/lib/            content loading, site config
content             content/            packages · destinations · testimonials · faqs ·
                                        blog · settings — the live content (edit via CMS)
CMS                 public/admin/       Sveltia CMS (config.yml → your GitHub repo)
assets              public/images/      photos served as-is (keep uploads < ~500 KB)
build output        out/                generated by npm run build (never committed)
config              next.config.ts      static export, trailingSlash, unoptimized images
                    wrangler.toml       Cloudflare Pages project config
archive             content-archive/    older packages/destinations kept for reference
```

## Editing content

**Easy way (no code):** open `/admin` on the deployed site, sign in with
GitHub, edit, save. Each save is a commit to this repo → automatic redeploy.

**Git way:** the markdown files in `content/` are the source of truth —
frontmatter fields match the CMS forms. Photos live in `public/images/`.

## Deployment

Full, beginner-proof runbook: **[`CLOUDFLARE-DEPLOY.md`](./CLOUDFLARE-DEPLOY.md)**
(GitHub → Cloudflare Pages → custom domain → CMS → analytics → email →
troubleshooting). Hosting cost: **₹0/month** on the free tier.

Before any deploy you can re-run the same audit Cloudflare's limits are
checked against:

```bash
npm run build && npm run verify:export
```
